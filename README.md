# Grid Portfolio

### Main Purpose

The point of this bot is to allow the user to fold and unfold a piece of A4 paper to learn about dimensions, surface area, volume, and SPACE involved. (The SPACE here is either how much space there is on top of the sheet of paper or how much space the thickness of the paper creates.)

### Commands

Note: the names for these commands are a bit... strange. I kind of didn't understand what exactly each command would do, or even how many there would be, when I initially made them, so the names don't really fit what they do.

#### /folding-paper-help
This command just lets you know about this project, but doesn't give you more information than this readme, so it's rather useless.

#### /folding-paper-paper
This command brings up an interface where the paper can be folded or unfolded. It also shows the dimensions, surface area, volume, and one extra statistic about the paper. This extra statistic is "SPACE," which is the amount of room in square units on top of the paper. An example is also given of what item can fit in the SPACE on top of the paper, though most of the information is missing. If a user has any idea of what might work, they can submit a request, which will then be reviewed.

#### /folding-paper-space
This command brings up an interface where the paper can be folded or unfolded. It also shows the dimensions, surface area, volume, and one extra statistic about the paper. This extra statistic is thickness, which is, like, the thickness of the paper. An example is also given of what item can fit in amount of SPACE created by the paper's thickness, though most of the information is missing. If a user has any idea of what might work, they can submit a request, which will then be reviewed.
